# 売買チャート PC版 1.2.0

WindowsのMicrosoft EdgeまたはGoogle Chromeで使うHTML版です。インストールは不要です。

1. `trade-chart-pc-v1.2.zip` を保存します。
2. ZIPを右クリックし「すべて展開」を選びます。
3. 中の `trade-chart-pc.html` をEdgeまたはChromeで開きます。
4. 上部の「Excel / CSVを追加」から取引履歴を読み込みます。

移動平均線・パラボリック・RCI・MACD・ボリンジャーバンド、線描画、RR、銘柄別損益、チャートへの取引別損益表示に対応します。

個人の取引履歴は含まれていません。損益計算には、新規と決済の両方の約定日時・約定数量・約定単価が必要です。注文履歴だけでは算出できません。金額はFIFOによる概算で、手数料・税金・金利等を除きます。

同じブラウザ内で自動保存し、「履歴入りHTMLを保存」でバックアップできます。株価の初回取得にはネット接続が必要です。

ブラウザでCSVの追加、価格チャート、損益の集計・表示、設定の保存・復元、HTMLによるバックアップ・オフライン復元を確認済みです。Windows実機での検証は未実施です。

## 1.2.0 の追加機能

チャート上に点線の十字カーソルを表示します。下側に指したローソク足の時刻、左側にカーソル位置の価格を表示します。

ストキャスティクスは下段に%K・%Dを表示します。初期値は14・3・3です。「設定」でオン・オフ、高値・安値の期間、%K平滑化、%D期間を変更できます。高値と安値が同じ場合は50とし、必要な本数に満たない部分は描きません。

計算テスト、カーソルの時刻・価格・ズームへの追従、設定の保存・HTML復元、指標のオン・オフと画面の高さを確認済みです。
