# 売買チャート PC版 1.5.0

WindowsのMicrosoft EdgeまたはGoogle Chromeで使うHTML版です。インストールは不要です。

1. `trade-chart-pc-v1.5.zip` を保存します。
2. ZIPを右クリックし「すべて展開」を選びます。
3. 中の `trade-chart-pc.html` をEdgeまたはChromeで開きます。
4. 上部の「Excel / CSVを追加」から取引履歴を読み込みます。

## 今回の変更：読み込み当日から過去1か月の分足を自動取得

「履歴の読み込み時に自動取得」は初期状態でオンです。Excel/CSVを読み込むと、そのファイルの銘柄について、読み込んだ当日（日本時間）から過去1か月の分足を順番に取得します。注文履歴に含まれる銘柄も対象です。連携フォルダーからのファイル追加も対象になります。

11月25日に読み込んだ場合は10月25日〜11月25日が対象です。1か月前の同日が存在しない場合は、その月の末日を使います。取引日を基準にするものではありません。

- 初期設定は1分足。「取得する足」で5分足を選んだ場合は5分足として保存・表示します。
- 最大7日ずつの区間に分け、新しい期間から順番に取得します。
- 銘柄ごとに取得日数・本数と、区間別の成功・データなし・失敗・未取得を表示します。
- 取得できた日は「最新の取得日を表示」や「保存済み」から開けます。
- 保存済み区間は再利用し、当日を含む区間は1分経過後の再取得時に更新します。
- 「全銘柄の1か月分を取得」で、取り込み済みの全銘柄を取得・再試行できます。
- 「取得を停止」で中断できます。取得済み株価・取引履歴は保持します。
- 以前の200件上限による株価の自動削除を廃止しました。端末の保存容量を超えた場合は保存失敗を表示します。

提供元の保存期間、休場日、通信制限などにより1か月分がそろわない場合があります。欠けた株価を推定したり、1分足を5分足で補ったりしません。HTTP 429のアクセス制限時は追加取得を停止し、残りの未取得銘柄数を表示します。時間を置いて再試行してください。

「履歴入りHTMLを保存」のバックアップには取得済みの株価・取得結果・自動取得設定も含まれます。自動保存失敗時には必ずHTMLでバックアップしてください。

## これまでの機能

全体・銘柄別にプロフィットファクター（PF）、ペイオフレシオ、平均利益・平均損失を追加しました。集計期間は取り込み済み全期間と選択日（決済日）を切り替えられます。

- PF＝利益合計÷損失合計の絶対値。
- ペイオフレシオ＝平均利益÷平均損失の絶対値。
- FIFOで対応した1組を1件と数えます。分割約定・分割決済は別の組です。同値は両平均から除外します。
- 損失なし・利益なし・同値のみ・データなしは、その状態を表示します。

「買いRR」「売りRR」で指定した価格から予定リスクリワードを表示します。複数ある場合は選択中、未選択なら最後に作成したRRを表示します。実績の平均損益とは別の値です。

チャート上部に選択日の損益、選択取引の損益、予定RRを小さく表示します。ズームして決済位置が画面外に出ても選択取引の金額は表示を維持し、←／→で決済位置の方向を示します。取引期間が画面内を通る場合も描画します。損益ラベルを小型化し、重なりを避けて配置します。描画は最大12組、選択日合計は全対応分です。

## 前回までの変更を含みます

時刻をローソク足エリアの横軸直下、RCI・MACD・ストキャスティクスより上に表示します。価格目盛りは表示範囲に応じた50円・100円などの切りのよい数字に揃えます。

「過去の1分足」で日付を指定し、選択銘柄の株価を取得できます。取引のない日も指定可能です。「保存済み」から取得済みの日付を選び直せます。過去の1分足は提供元の保存期間に限られ、休場日や通信エラーの場合も取得できません。

移動平均線・パラボリック・RCI・MACD・ボリンジャーバンド・ストキャスティクス、十字カーソル、線描画、RR、銘柄別・取引別損益表示にも対応します。

## 保存と計算

個人の取引履歴は含まれていません。損益計算には新規と決済の両方の約定日時・約定数量・約定単価が必要です。注文履歴だけでは算出できません。金額はFIFOによる概算で、手数料・税金・金利・含み損益等を除きます。対応できた分だけを集計します。

同じブラウザ内で自動保存し、「履歴入りHTMLを保存」でバックアップできます。取得済み株価もバックアップに含めます。
