# 売買チャート Mobile 1.1.0

Android向けの取引振り返りアプリです。

## インストール

1. `trade-chart-mobile-v1.1.zip` を保存して解凍します。
2. 中の `trade-chart.apk` をAndroidで開き、インストールまたは更新します。
3. アプリの「データ」からCSV・Excel・履歴入りHTMLを追加します。

この配布ファイルには個人の取引履歴・内蔵Excel・メモは含まれません。すでにインストール済みの場合は、同じ署名・同じアプリIDで端末内の履歴を引き継ぎます。

## 機能

- SMA・パラボリック・RCI・MACD・ボリンジャーバンドの設定
- ライン描画、リスクリワードの描画と比率表示
- 銘柄別損益、取引を結ぶ線と利益・損失額の表示
- 振り返りメモ、自動保存、履歴入りHTMLによるバックアップ

損益は約定履歴をFIFOで対応させた手数料・税金・金利を除く概算です。注文履歴だけでは損益を計算できません。

Android 8以降と更新されたAndroid System WebViewを想定しています。画面操作・計算・保存復元・APKの署名を確認済みです。Android実機での操作は未検証です。
